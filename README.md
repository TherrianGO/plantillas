# Plantillas de convocatoria omnicanal

Abra esta carpeta en VS Code. Abra `index.html` en su navegador para elegir un canal, o abra directamente el `index.html` de cualquiera de las seis subcarpetas. Funciona con `file://`, sin instalaciones, servidor, dependencias ni conexión.

Cada canal incluye HTML, CSS y un JS que abre un aviso local al pulsar los botones. Escape o Cerrar cierran el aviso. No hay formularios ni envíos, enlaces externos ni cuentas conectadas. El logo se incluye en assets/logo.png.

Contenido: sección III del documento ANUNCIOS_SELECCION.docx guardado en la carpeta superior. Se preservan las redacciones específicas de cada canal: portales incluyen servicios masivos; redes y LinkedIn mantienen Retail o E-commerce. Las plataformas se recrean visualmente con fines académicos, sin afiliación oficial. Se omite el número de seguidores del encabezado de LinkedIn para no representar una cifra real. No se inventan métricas sociales, fechas, enlaces de postulación ni postulantes.

Los afiches son una síntesis visual; el texto de cada sección aparece completo en la descripción de su canal. Las etiquetas de ubicación y jornada provienen de la convocatoria. Los enlaces mencionados en el texto fuente no fueron proporcionados; por eso la interacción solo muestra el aviso de demostración. El correo se presenta como texto, sin activar envíos.

Git se inicializó únicamente en esta carpeta antes de crear las plantillas. Sin commit ni remoto.
